# 🏍️ MotoECU Pro

**Dashboard avanzado para ECU de motos - Sistema OBD2 Delphi MT05.A**

## 🚀 Características

✅ **Conexión Bluetooth OBD2** - Sincronización con adaptadores ELM327/STN  
✅ **Telemetría en Tiempo Real** - Lectura de RPM, velocidad, temperatura, AFR  
✅ **Interfaz Responsive** - Optimizada para móvil, tablet y escritorio  
✅ **Modo Simulación** - Prueba la app sin adaptador  
✅ **PWA Compatible** - Instalable como app nativa  
✅ **Offline Ready** - Funciona sin conexión a internet  

## 📱 Usar la App

### ✨ Opción 1: Online (Acceso Directo)

🔗 **https://brunopintura17-stack.github.io/Moto-ecu-/**

### 📲 Opción 2: Instalar como App

1. Abre en tu navegador: https://brunopintura17-stack.github.io/Moto-ecu-/
2. Toca el menú ⋯ (tres puntos)
3. Selecciona **"Instalar app"** o **"Añadir a pantalla de inicio"**
4. ¡Listo! Ya está en tu pantalla de inicio

### 🎮 Opción 3: Modo Simulación

- Haz clic en **"Modo Simulación"** para probar sin adaptador OBD2
- Verás datos ficticicios realistas de un motor

## 🔧 Requisitos

- ✅ Navegador moderno (Chrome, Firefox, Safari, Edge)
- ✅ Adaptador OBD2 Bluetooth (opcional - hay modo simulación)
- ✅ Permisos de Bluetooth en tu dispositivo

## 📊 Pantallas

### Enlace
- Conexión OBD2 Bluetooth
- Conexión USB directo
- Modo Simulación

### Telemetría
- Velocímetro gigante en KM/H
- RPM en tiempo real
- Marcha detectada automáticamente
- Temperatura del motor
- AFR (Air-Fuel Ratio)
- TPS (Acelerador)

### Lab
- Consola hexadecimal K-Line
- Envío de comandos OBD2 raw
- Monitor de tramas en tiempo real

### Mapas
- Editor de mapas de combustible 12x12
- Visualización de valores en grid
- Guardar mapas en almacenamiento local
- Flash de mapas a ECU

## 🛠️ Tecnología

- HTML5 / CSS3 / JavaScript
- TailwindCSS para diseño responsive
- Lucide Icons
- Web Bluetooth API
- Serial API (USB)
- Service Workers (PWA)
- Manifest.json para instalación
